# Desktop study

## Verified current facts (2026-09-27)

- Official PyTorch Windows guidance supports Python 3.9-3.12 and directs CUDA-capable Windows users to its pip/CUDA selector: https://docs.pytorch.org/get-started/locally/
- Databento defines MBO as order-keyed L3 and MBP-10 as aggregated top-ten L2. MBO contains separate event/receive timestamps and venue sequence: https://databento.com/docs/knowledge-base and https://databento.com/docs/schemas-and-data-formats/mbo
- Databento advertises downloadable public samples, but sample/license terms must be inspected before acquisition; API historical access otherwise uses credentials: https://databento.com/tick-data
- Chronos source is Apache-2.0 and the official repository now includes Chronos-2: https://github.com/amazon-science/chronos-forecasting
- TimesFM source is Apache-2.0; weight licenses are version-specific, so no weights will be fetched until the chosen version is recorded: https://github.com/google-research/timesfm

FI-2010 remains a short normalized classification benchmark, not evidence for modern-regime economics. Provider-specific Dukascopy L1 is decentralized-source top-of-book and cannot support observed queue fills. External baseline eligibility requires official code/version/license and a faithful protocol; otherwise results are non-headline diagnostics.
