# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's security-advisory feature
for this repository. Do not open a public issue containing exploit details, credentials, or
sensitive data. The maintainers will acknowledge and triage reports on a best-effort basis.

## Secrets and market data

Never commit API keys, access tokens, passwords, `.env` files, private keys, credential files,
provider session material, or licensed raw market data. If sensitive material is accidentally
committed, revoke it immediately and contact the maintainers before any further push.

MarketForge-QTR is research software. Its simulations and outputs must not be treated as a
security control, brokerage safeguard, or production trading authorization mechanism.
